# 我的代办 Todo

> [← Deck 文档](README.md)

- **入口路由**：`/todo`
- **源码位置**：[src/views/deck/todo/index.vue](../../src/views/deck/todo/index.vue)
- **依赖**：solarlunar（农历 / 节气）

## 功能定位

月历 + 当日列表的代办管理，带农历、黄历与提醒通知。

## 页面结构

```
标题栏 + 新建按钮
  ↓
左侧月历（6×7 周起始，含黄历条）
  ↓
右侧当日代办列表（全部/待办/已完成筛选）+ 新建/编辑弹窗
```

## 核心功能

- **月历**：6×7 周起始布局；solarlunar 农历 / 节气 / 公农历节日；内置 2025 / 2026 法定节假日休 / 班徽标
- **黄历条**：干支、生肖、十二值神、冲煞、宜忌
- **待办圆点**：每格最多 3 个圆点 + 溢出计数，点击格子切换当日
- **列表**：按全部 / 待办 / 已完成筛选，完成项沉底；勾选完成 / 恢复；双击或按钮编辑；删除二次确认
- **表单校验**：标题 / 描述必填失焦校验；日期时间选择
- **提醒时机**：不提醒 / 准时 / 提前 5、15、30、60 分钟 / 提前 1 天
- **附件**：多选上传（单个 ≤20MB，ArrayBuffer 随记录存储，点击还原下载）
- **到期提醒**：App.vue 全局 30s 轮询 `remindAt` 触发系统通知，错过提醒补发；通知点击跳转 `/todo`
