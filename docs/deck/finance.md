## 一、基金自选（fund.vue）

持仓列表与实时估值收益看板。

### 页面结构

```
ToolShell
  ├─ 汇总卡（总市值 / 当日收益 / 持仓收益 / 成本 + 市场状态胶囊 + 估值时间）
  └─ 持仓行列表 + 添加 / 编辑弹窗
```

### 核心功能

- **60s 自动刷新**：倒计时按钮状态机（倒数 → 刷新中 → 成功 / 失败 2s）；交易时段判断（交易中 / 午休 / 收盘，非交易时段暂停倒数）
- **估值涨跌闪烁**：红涨绿跌动画
- **数字动效与隐私**：AnimatedNumber 数字滚动；金额隐私模式（`fundHideAmount` 持久化，含 localStorage 一次性迁移）
- **骨架屏**：首轮加载骨架占位
- **行操作**：置顶 / 上移 / 下移 / 编辑 / 删除
- **添加持仓**：6 位代码 300ms 防抖查询；按份额 / 按金额双模式录入；成本单价默认最新净值（限 4 位小数）；重复添加覆盖确认；保存前先取估值防中间态闪烁
- **详情跳转**：行点击进入 `/finance/fund/:code`

## 二、基金详情（detail.vue）

单只基金的估值走势 / 历史净值 / 档案详情页。

### 页面结构

```
概要条（估算净值 + 昨收 + 我的持仓卡）
  ↓
三 Tab：估值走势 / 历史净值 / 基金信息
```

### 核心功能

- **盘中分时图**：昨收中轴对称 + 百分比刻度（0% 处标昨收价）；悬停十字线 / tooltip；末端最新价胶囊
- **历史走势**：1 月 / 3 月 / 6 月 / 1 年 / 3 年 / 全部范围切换；>240 点等距降采样；区间涨跌幅着色
- **历史净值 Tab**：走势图 + 倒序净值列表
- **基金信息**：10 字段网格（全称 / 类型 / 成立 / 公司 / 托管 / 规模 / 基准 / 风险等级 R1-R5 等）+ 基金经理卡片（照片 / 评分 / 任职 / 规模）
- **自动刷新**：交易时段 60s、非交易 300s
- **页签标题联动**：加载后更新页签标题（`tagsView/UPDATE_TAB_TITLE`）
- **外链**：跳转东方财富
